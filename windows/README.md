# Windows client

Planned native desktop client for STATION LIVE IPTV 4K.

Initial requirements:
- Windows 10/11 x64.
- Xtream Codes and M3U/M3U8 connection profiles.
- Live TV, movies, series, EPG, search and favorites where provided by the authorized source.
- Keyboard, mouse and remote-friendly navigation.

Implementation framework and packaging will be selected after the Android connection contract and playback architecture are validated. No Windows executable exists yet.
